# Student Marketplace

This is a simple web project built for students to buy and sell items like books, furniture, and other useful things.

It is built using HTML, CSS, JavaScript, PHP, and MySQL.

To run this project, place it in the XAMPP htdocs folder, start Apache and MySQL, import the database, and open it in your browser using localhost.

The project includes basic features like user login, product listing, and cart/wishlist functionality.
